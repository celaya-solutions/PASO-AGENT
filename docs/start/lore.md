# PASO identity

**PASO** is an AI agent by **Celaya Solutions Research**, based in El Paso, Texas.

Use this description for public-facing copy:

> PASO is a self-hosted AI agent that connects messaging channels, tools, models, and devices through one gateway you control.

## Naming

- Write the product name as **PASO**.
- Credit **Celaya Solutions Research** as the developer and maintainer.
- Use [hello@celayasolutions.com](mailto:hello@celayasolutions.com) for general contact.
- Keep lowercase `openclaw` when it names the command, npm package, config directory, environment-variable prefix, protocol field, or another compatibility interface.
- Keep third-party product and tool names unchanged. For example, the Lobster workflow tool remains `lobster` where the docs refer to that actual tool.

## Project origin

PASO is built on the open-source [OpenClaw framework](https://github.com/openclaw/openclaw). The fork preserves the framework's MIT license and required third-party notices while giving the agent its own user-facing identity, stewardship, documentation, and repository.

The PASO source is maintained at [celaya-solutions/PASO-AGENT](https://github.com/celaya-solutions/PASO-AGENT).

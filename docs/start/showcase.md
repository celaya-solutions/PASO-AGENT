# PASO use cases

PASO brings an AI agent into messaging channels, a browser-based Control UI, terminals, and supported devices. The examples below describe capabilities you can configure; they are not customer endorsements or claims about third-party deployments.

<CardGroup cols={2}>
  <Card title="Research assistant" icon="book-open">
    Collect source material, summarize findings, keep project notes, and deliver updates through a chosen messaging channel.
  </Card>
  <Card title="Software workflow" icon="code">
    Work with repositories, run approved commands, review changes, and keep one session available from desktop or mobile.
  </Card>
  <Card title="Operations helper" icon="list-checks">
    Schedule recurring checks, receive alerts, and route follow-up work through configured tools and webhooks.
  </Card>
  <Card title="Private knowledge agent" icon="database">
    Search files and notes available to the agent while keeping the Gateway and its state on infrastructure you control.
  </Card>
  <Card title="Multi-channel assistant" icon="messages-square">
    Use one Gateway across supported messaging plugins without creating a separate agent configuration for every channel.
  </Card>
  <Card title="Device-assisted tasks" icon="smartphone">
    Pair supported nodes for device capabilities, then restrict access with authentication, policy, and approvals.
  </Card>
</CardGroup>

## Start safely

Begin with one operator, one model provider, and one channel or the Control UI. Add tools gradually, review [Security](/gateway/security), and require approvals where a mistake could change important data or systems.

For setup, continue to [Getting started](/start/getting-started). For questions about a PASO deployment, contact [hello@celayasolutions.com](mailto:hello@celayasolutions.com).

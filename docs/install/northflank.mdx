Deploy PASO on Northflank from the Celaya Solutions Research source repository and access it through the web Control UI.

## How to get started

1. Create an [account on Northflank](https://app.northflank.com/signup) if you don't already have one.
2. Create a combined service from [celaya-solutions/PASO-AGENT](https://github.com/celaya-solutions/PASO-AGENT) and select its `Dockerfile` build path.
3. Attach a volume mounted at `/data`.
4. Set these required environment variables:
   - `OPENCLAW_GATEWAY_TOKEN` (use a strong random value)
   - `OPENCLAW_STATE_DIR=/data/.openclaw`
   - `OPENCLAW_WORKSPACE_DIR=/data/workspace`
5. Deploy the service and let Northflank build the PASO source image.
6. Wait for the deployment to complete, then click **View resources**.
7. Open the PASO service.
8. Open the public PASO URL at `/openclaw` and connect using the configured shared secret. This template uses `OPENCLAW_GATEWAY_TOKEN` by default; if you replace it with password auth, use that password instead.

From the Northflank shell, run the read-only deployment preflight:

```bash
openclaw doctor --json
```

## What you get

- Hosted PASO Gateway + Control UI
- Persistent storage via a Northflank Volume (`/data`) so `openclaw.json`, shared and per-agent SQLite auth stores, channel/provider state, sessions, and workspace survive redeploys

## Connect a channel

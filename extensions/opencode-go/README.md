# PASO OpenCode Go Provider

Official PASO provider plugin for the OpenCode Go model catalog.

OpenCode Go is bundled with PASO for this release; no separate plugin
installation is required.

Configure `OPENCODE_API_KEY` or `OPENCODE_ZEN_API_KEY`, then select an
`opencode-go/...` model.

See <https://github.com/celaya-solutions/PASO-AGENT/blob/main/docs/providers/opencode-go.md> for setup and the current
model catalog.

# PASO Volcengine Provider

Official PASO provider plugin for Volcengine models, the Volcengine coding
plan, and Volcengine Speech text-to-speech.

Install from PASO:

```bash
openclaw plugins install @openclaw/volcengine-provider
openclaw gateway restart
```

See <https://github.com/celaya-solutions/PASO-AGENT/blob/main/docs/providers/volcengine.md> for model and speech setup.

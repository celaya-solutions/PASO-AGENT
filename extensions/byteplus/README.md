# PASO BytePlus Provider

Official PASO provider plugin for BytePlus model inference and Seedance
video generation.

Install from PASO:

```bash
openclaw plugins install @openclaw/byteplus-provider
openclaw gateway restart
```

Set `BYTEPLUS_API_KEY`, then select a `byteplus/*` or `byteplus-plan/*` model.

See <https://github.com/celaya-solutions/PASO-AGENT/blob/main/docs/concepts/model-providers.md#byteplus-international>
for model setup and <https://github.com/celaya-solutions/PASO-AGENT/blob/main/docs/tools/video-generation.md> for
Seedance video generation.

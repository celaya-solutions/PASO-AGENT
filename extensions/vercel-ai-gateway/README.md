# Vercel AI Gateway PASO provider

Official PASO provider plugin for Vercel AI Gateway.

## Install

```sh
openclaw plugins install @openclaw/vercel-ai-gateway-provider
```

## Docs

See `docs/providers/vercel-ai-gateway.md` in the PASO repository, or the published docs at `https://github.com/celaya-solutions/PASO-AGENT/blob/main/docs/providers/vercel-ai-gateway.md`.
